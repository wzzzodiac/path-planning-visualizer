# Path Planning Visualizer

Interactive browser-based visualization of common path-planning algorithms.

## Algorithms

- A* Search
- Dijkstra
- Greedy Best-First Search

## Features

- Interactive start and goal nodes
- Click-and-drag wall drawing
- Animated search exploration
- Final path visualization
- Nodes explored, path length and compute-time metrics
- Adjustable animation speed
- Random obstacle generation
- Responsive layout

## Run locally

Open `index.html` in a browser.

## GitHub Pages

Once GitHub Pages is enabled for the repository, the project can be served directly from the `main` branch root.

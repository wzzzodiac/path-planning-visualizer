Controls & map rules +

Orbit: drag to rotate. Zoom with the wheel or + / −. Edit: drag to paint, or drag START and GOAL. Right-click erases. On touchscreens, use one finger in the selected mode.

The terrain is a 3D view of a 2D grid. Height is decorative. Normal cells cost 1, rough cells 4 and heavy cells 8. Diagonal steps multiply that cost by √2; cutting through blocked corners is disabled.

A* and Dijkstra find the cheapest route. Greedy can find a more expensive route. The rover replay illustrates the path at a constant cell rate; it does not simulate terrain-dependent travel time.
